# Radar report

Use the repository `AGENTS.md` boundaries. Select AI/developer sources or the education planner from the user's request, then read only the relevant sections of `docs/CUSTOMIZATION_GUIDE.md` and the chosen collector.

Validate source dates, preserve history-based velocity scoring, and produce Korean report content in `reports/`; the education planner returns three topics. Follow the source's actual data and report contracts rather than assuming a model, elapsed time or mandatory browser subagent.

The existing collectors invoke delivery. Do not launch them under report-only authorization unless the inspected configuration/code path demonstrably prevents all sends and publication. Otherwise collect and draft through available read-only tools, and state any workflow limitation. A report request alone never authorizes delivery. When delivery is explicitly approved, verify the destination and final content before using the approved send path.
